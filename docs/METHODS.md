# 分析方法

[中文](METHODS.md) · [English](METHODS.en.md) · [项目说明](../README.md)

## 数据与测量

研究使用 622 份在线问卷。Y 为 Q21 的支付溢价意愿，保留 1–5 有序等级。技术认知 T 为 Q15（重要性）和 Q16（安全性）的均值；功能价值 V 为 Q22–Q25（自适应巡航、车道保持、自动泊车、拥堵辅助）的均值。M1 为 Q18 的驾驶乐趣评价，M2 为 Q19 的出行效率评价。

所有模型的背景控制集为性别、年龄、学历、收入、驾龄和驾驶频率。类别变量采用参照组哑变量，不把类别代码当作连续年龄或金额。组合指标要求所用题项完整，各分析使用所需变量的完整记录。

题目原文、代码范围和输出文件见[数据说明](../data/README.md)。

## 有序 Logit

主模型为：

```text
logit P(Y > k) = βT T + βV V + γ′C − κk,   k = 1, 2, 3, 4
```

C 为六项背景变量的类别编码，κ 为等级阈值。系数在比例优势设定下对各阈值保持相同。exp(β) 是指标增加 1 分时、在其他变量不变条件下跨越阈值的优势比。

报告展示当前变量定义下加入控制变量的模型（结果文件中 `specification=primary`、`model=controlled`）。同时保存不含控制变量的模型、完整系数、拟合诊断和辅助 VIF。VIF 的辅助计算含截距，有序 Logit 本身不额外加入常数列。

T 的 OR 为 2.08（95% CI：1.62–2.68），V 为 3.83（2.84–5.16）。OR 描述条件关联，不是概率倍数。比例优势假设尚未专项检验。

## 探索性间接路径

分别估计五条路径：T→M1→Y、T→M2→Y、V→M1→Y、V→M2→Y 和 T→V→Y。每条路径使用两个含截距和控制变量的 OLS 方程：

```text
M = α + aX + δ′C + εM
Y = θ + c′X + bM + η′C + εY
间接关联 = a × b
```

按受访者有放回重抽样 5,000 次，随机种子为 42。95% 百分位区间取系数乘积分布的 2.5% 与 97.5% 分位数。当前每条路径均有 5,000 次有效估计。

| 路径 | a×b | 95% Bootstrap 区间 |
|---|---:|---|
| T→M1→Y | 0.256 | 0.180–0.330 |
| T→M2→Y | 0.180 | 0.100–0.256 |
| V→M1→Y | 0.257 | 0.183–0.332 |
| V→M2→Y | 0.163 | 0.079–0.248 |
| T→V→Y | 0.351 | 0.258–0.438 |

各路径单独估计，前四条不额外控制另一核心认知变量，因而可能存在遗漏变量混杂。这不是同时估计的平行中介模型，各路径的乘积不能相加为总体贡献。区间为逐路径区间，未作五条路径的同时区间校正。OLS 将等级评分近似为等距连续量，横截面数据也无法确定时间顺序。

## 人群差异

分别检验性别、年龄、收入、驾龄和驾驶频率。受限模型包含 T、V、六项控制变量及分组主效应；扩展模型加入 T×分组与 V×分组。两者在同一完整样本上估计。

```text
LR = 2 × (logLik扩展 − logLik受限)
```

自由度为两设计矩阵的实际秩差。模型须收敛后才报告 LR 检验，五个原始 p 值采用 Holm 方法校正。

性别与年龄的原始 p 值为 0.013 和 0.042，校正后为 0.063 和 0.170。五项校正值均高于 0.05，本样本未提供校正后显著的斜率差异证据。

## 预测比较

使用相同的五折分层划分（打乱，种子 42），比较以下三组输入：

1. 六项背景控制变量；
2. 控制变量加 T、V；
3. 控制变量加 T、V、M1、M2。

每组输入均评估多数类基线、有序 Logit 和随机森林。多数类由训练折确定；随机森林使用 200 棵树、最大深度 6。模型训练和测试按折分开。题项均值逐行构造，类别编码采用配置中声明的水平。

| 指标 | 含义 |
|---|---|
| Accuracy | 预测等级与真实等级完全相同的比例 |
| Macro-F1 | 五个等级 F1 的宏平均 |
| QWK | 二次加权 Kappa，考虑等级误差并校正随机一致性 |
| Ordinal MAE | 预测与真实等级相差的平均绝对值 |

报告表中的指标是五折平均值。扩展输入下，有序 Logit 的 QWK 为 0.685、准确率为 54.5%；随机森林为 0.619 和 53.5%。保存的指标支持这次划分内的比较，不等于外部样本验证。

现有折指标中的 `ok` 表示该折没有抛出异常；原预测流程未单独保存有序 Logit 的优化器收敛诊断。

## SHAP

SHAP 解释扩展随机森林预测高溢价意愿 P(Y≥4) 的概率。每折使用其训练数据构造解释器背景，解释该折测试样本；对等级 4、5 的概率归因求和，再汇总平均绝对 SHAP 值。

图中包含 T、V、M1、M2 和编码后的背景变量，共 23 个输入特征。平均绝对值衡量预测归因大小，不提供作用方向。功能价值、技术认知、驾驶乐趣和出行效率排在前四。

## 研究局限

- 数据来自横截面便利样本，包含自报与共同方法偏差；支付溢价意愿不等于实际购买。
- T、V 为项目题项组合，未经外部量表验证；内部一致性统计不等于构念效度。
- V 的题目涉及功能对购买意愿的影响，与 Y 概念接近。
- 题项曾在同一数据上进行探索，当前交叉验证未覆盖此前选题的影响。
- 比例优势假设、路径连续化近似和外部泛化仍是解释限制；各折有序 Logit 的优化器收敛也没有独立记录。
