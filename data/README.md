| 项目 | 说明 |

| 数据形式 | 在线问卷导出的 CSV |

报告页使用汇总 JSON；分析从 CSV 的原始题项读取回答。原始列名与题号映射见 [`src/config.py`](../src/config.py)，数据处理见 [`src/data_schema.py`](../src/data_schema.py)。

## 研究变量

| 符号 | 含义 | 题项 | 构造与编码 |
|---|---|---|---|
| Y | 支付溢价意愿 | Q21 | 单题，1–5 有序等级 |
| T | 技术认知：重要性与安全性评价 | Q15、Q16 | 两题回答完整时取算术均值 |
| V | 功能价值：辅助驾驶功能评价 | Q22–Q25 | 四题回答完整时取算术均值 |
| M1 | 驾驶乐趣评价 | Q18 | 单题，1–5 |
| M2 | 出行效率评价 | Q19 | 单题，1–5 |

T 和 V 是题项组合指标。内部一致性 α 分别为 0.858 和 0.871，这些统计量反映题项间的一致程度。构念含义及测量局限见[分析方法](../docs/METHODS.md)。

## 数据处理

- 按原始列名及题号匹配题项，已有处理列不作为模型输入。
- 原始回答转换为数值；不能转换的值记为缺失。
- T、V 使用完整题项均值，任一组成题缺失时该组合值记为缺失。
- Q15–Q29 的评分范围为 1–5；背景题按各自的类别范围读取。
- 各模型使用所需变量的完整记录。主分析题项和控制变量在本数据中没有缺失，主模型样本为 622。
- 数据质量记录包括重复行、缺失、取值范围及组合题项统计，结果保存在 `audit.json`。

## 结果文件

完整运行的输出位于 `figures/runs/run-YYYYMMDD-HHMMSS/`。

| 文件 | 内容 |
|---|---|
| `audit.json` | 样本及题项诊断 |
| `ordered_logit_coefficients.csv` | 有序 Logit 系数、OR、区间和 p 值 |
| `ordered_logit_diagnostics.json` | 拟合诊断 |
| `mediation_paths.csv` | 五条间接路径及 Bootstrap 区间 |
| `heterogeneity_results.csv` | 分组 LR 检验与 Holm 校正 |
| `ml_summary.csv` | 模型及输入组合的五折平均指标 |
| `ml_fold_metrics.csv` | 各折指标 |
| `ml_oof_predictions.csv` | 折外预测 |
| `shap_importance.csv` | 平均绝对 SHAP 排序 |
| `run_metadata.json` | 数据与代码版本、运行配置 |

Notebook 读取这些结果并展示研究表图。运行及目录选择见 [Notebook 说明](../notebooks/README.md)。
